# Automotive CAN-to-Bluetooth Interface

The hardware design of an automotive CAN-to-Bluetooth communication interface designed for wireless access to vehicle CAN networks. The board combines CAN bus connectivity, Bluetooth wireless communication, galvanic isolation, automotive-grade power conditioning, and onboard flash storage in a compact embedded platform. 

The design features a CYW20829 Bluetooth module, isolated CAN transceiver architecture, SPI flash memory, SWD debugging interface, and a protected 24V automotive power input stage. The power subsystem includes surge protection, filtering, buck regulation, isolated DC/DC conversion, and dedicated power domains for improved reliability in automotive environments. 

To improve signal integrity, safety, and EMC performance, the design incorporates galvanic isolation using an isolated DC/DC converter, digital isolator, and optocoupler. Additional layout considerations include RF antenna keep-out regions, CAN bus filtering, ESD protection, thermal management, and creepage/clearance enhancements through isolation slots

## Key Features

- Automotive 24V power input support
- CAN bus communication interface
- CYW20829 Bluetooth wireless connectivity
- Galvanically isolated CAN and logic domains
- SPI flash memory for firmware and data storage
- SWD programming and debugging interface
- TVS, ESD, and surge protection circuitry
- RF-aware PCB layout for Bluetooth operation
- Automotive-grade power conditioning and filtering
- Safety-focused isolation and thermal design
